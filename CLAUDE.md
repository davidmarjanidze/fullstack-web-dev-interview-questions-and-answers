# CLAUDE.md

## Rules

- Whenever any content in this repo is added or updated, update the `_Last updated: <Month> <Day>, <Year>_` line at the top of [README.md](README.md) to the current date (for example, `_Last updated: October 29, 2026_`).
- Whenever any questions and answers markdown file (for example, [front-end/web-vitals.md](front-end/web-vitals.md)) is added or updated in any way, it must have the same `_Last updated: <Month> <Day>, <Year>_` line at the beginning, set to the current date. Put it right after the `#` title, separated by blank lines, the same as in [README.md](README.md). If the file does not have the line yet, add it.
